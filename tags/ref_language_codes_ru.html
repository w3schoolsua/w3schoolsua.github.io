ISO Языковые коди

HTML атрибут lang может использоваться для объявления языка вебстраницы или части вебстраницы. Это должно помочь поисковым системам и браузерам.

В соответствии с рекомендациями W3C вы должны объявить основной язык для каждой вебстраницы с помощью атрибута lang внутри тега <html>, как здесь:

<html lang='uk'>
...
</html>

В XHTML язык объявляется внутри тега <html> следующим образом:

<html xmlns='http://www.w3.org/1999/xhtml' lang='uk' xml:lang='uk'>
...
</html>

Также вы можете указать содержание вебстраницы, написанное двумя языками одновременно, в тегах <title> и <meta name='description' content='text, текст'>. Это можно сделать, используя атрибут lang для указания языка. Например, если вебстраница содержит содержание, написанное английским и украинским языками, то вы можете указать это так:

Пример

<html lang='en-US,uk-UA'>
  <head>
    <meta charset='utf-8'>
    <title lang='en'>Title</title>
    <title lang='uk'>Заголовок</title>
    <meta name='description' content='text' lang='en'>
    <meta name='description' content='текст' lang='uk'>
  </head>
  <body>
    <h1>Зміст веб-сторінки написано двома мовами</h1>
    <p>This text is written in English.</p>
    <p>Цей текст написано українською мовою.</p>
  </body>
</html>

ISO 639-1 Коды языков

ISO 639-1 определяет сокращение для языков.

В HTML и XHTML они могут использоваться в атрибутах lang и xml:lang.
