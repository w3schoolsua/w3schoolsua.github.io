URL‑кодирование преобразует символы в формат, который может быть передан через Интернет.

URL (Uniform Resource Locator) — Унифицированный указатель информационного ресурса

Веб‑браузеры запрашивают страницы с веб‑серверов с помощью URL‑адреса.

URL‑адрес — это адрес веб‑страницы в Интернете, например: https://www.w3schools.com.

URL‑кодирование (процентное кодирование)

URL‑адреса могут быть отправлены через Интернет только с использованием набора символов ASCII.

Поскольку URL‑адреса часто содержат символы вне набора ASCII, URL должен быть преобразован в корректный ASCII‑формат.

URL‑кодирование заменяет небезопасные символы ASCII на «%», за которым следуют две шестнадцатеричные цифры.

URL‑адреса не могут содержать пробелы. Обычно пробел заменяется знаком плюс (+) или последовательностью %20.

Попробуйте сами

Если нажать кнопку Submit («Отправить») ниже, браузер закодирует введённый URL перед отправкой на сервер. Страница на сервере покажет полученные данные.

Попробуйте ввести другие данные и снова нажмите «Submit» («Отправить»)

Функции URL‑кодирования

В JavaScript, PHP и ASP существуют функции для URL‑кодирования строки.

PHP имеет функцию rawurlencode(), а ASP — функцию Server.URLEncode().

В JavaScript можно использовать функцию encodeURIComponent().

Нажмите кнопку «URL Encode», чтобы увидеть, как JavaScript кодирует текст.

Примечание: функция JavaScript кодирует пробел как %20.
